# platform/data-raw/history

- tensift_daily_reserves_2026-08_to_10.csv: daily reserve (Mm3) and fill rate (%) for 5 Tensift-basin dams, Aug-Oct 2026, long format. Source: https://data.gov.ma (ABHT, dataset "Situation journalière des barrages dans le bassin du Tensift", resources Aout/Sept/Oct 2026). Retrieved 2026-11-19. Licence: ODbL (Open Data Commons Open Database License), per the data.gov.ma metadata. Coverage: 3 months only; not Souss-Massa.
- souss_massa_dam_list_abhsm.csv: list of the 9 Souss-Massa dams with approximate coordinates (no storage data). Source: https://data.gov.ma (ABHSM, "Liste des barrages dans le bassin hydraulique de Souss Massa", barrage_souss_massa.xlsx). Retrieved 2026-11-19. Licence: ODbL.
