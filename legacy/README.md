# Original internship materials

These files preserve the original WaterQualityProject:

- `WATER_QUALITY_INDEX_CALCULATION_(WQI).ipynb`: original notebook, including saved outputs.
- `Water quality.xlsx`: original input workbook.
- `requirements.txt`: original Python dependency list.
- `README.original.md`: original repository README, preserved verbatim.

The notebook and workbook remain together so its relative `Water quality.xlsx` reference still works when run from this directory. Its original dependencies are incomplete for a fresh Jupyter/Excel environment; see the audit notes in the main handoff.

This workbook is not a verified Souss-Massa dam dataset. Its raw weighted-sum “WQI” is not used in the new application and should not be interpreted as validated water-quality or potability evidence.

For the new app, use `../platform/`. For current project context, read `../HANDOFF.md`.
